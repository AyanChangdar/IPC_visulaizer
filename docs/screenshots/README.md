# Screenshot captures

Capture the running application and save the PNG files in this directory using the filenames in the [README gallery](../../README.md#screenshots-and-application-preview). For each capture, uncomment its image and caption in the README once the file has been added.

Use the actual dashboard or terminal output. For process-monitor captures, allow CPU sampling to populate before taking the screenshot. For recovery, capture a confirmed delivery in the next run after stopping the deadlock demonstration.
